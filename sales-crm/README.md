- ใช้งานจริง: https://claude.ai/artifact/HToQ97FAieqrXFCNAzS8q1
- โค้ดหน้าเว็บ: `index.html` (ไฟล์เดียว ไม่มี build step)
- ข้อมูลตั้งต้นจากชีต: `seed/*.tsv` และสคริปต์แปลง `seed/build_seed.py`

## ผู้ใช้และหน้าที่

| ผู้ใช้ | หน้าที่ใช้บ่อย | ทำอะไร |
|---|---|---|
| MD / Sales Director | ภาพรวมผู้บริหาร, ตั้งค่า | ดูยอดเทียบเป้า, คาดการณ์, ดีลที่ต้องดูแล, ตั้งเป้า, โอนงาน |
| เซลส์ (Bee, Nungning) | งานของฉัน, Pipeline, กิจกรรม | อัปเดตดีล, บันทึกการโทร/ประชุม, ดูนัดติดตาม |

## หน้าจอ

1. **ภาพรวมผู้บริหาร**: GP ที่ปิดได้เทียบเป้า (ทั้งปี / สะสม / รายไตรมาส / รายเดือน), คาดการณ์ทั้งปี
   (ปิดแล้ว + ดีลเปิด × % โอกาส), Pipeline coverage, Win rate, ลูกค้าใหม่, Scorecard รายเซลส์,
   Funnel, GP ตามบริษัทในเครือ, ดีลที่ต้องดูแล, ดีลใหญ่ที่กำลังลุ้น
2. **งานของฉัน**: ยอดเดือนนี้ของตัวเอง, งานที่ต้องตามวันนี้, ดีลที่ควรปิดเดือนนี้, นัด 7 วันข้างหน้า
3. **Pipeline**: บอร์ดลากวาง (Kanban) และตาราง, กรองตามเซลส์/บริษัท/ความร้อน/ช่วงเวลา, ส่งออก CSV
4. **ลูกค้า**: บริษัททั้งหมด รวมรายชื่อเป้าหมาย (IP-GGEZ, Fandom-SETech), ผู้ติดต่อ, ประวัติดีลและกิจกรรม
5. **กิจกรรม**: แทน Timesheet บันทึกการโทร ประชุม นำเสนอ และอัปเดตนัดติดตามของดีลไปพร้อมกัน
6. **Forecast**: เซลส์จัดดีลของเดือนเป็น Commit / Best Case / Pipeline / ไม่นับ, ตาราง Call (ปิดแล้ว + Commit)
   เทียบเป้า, ดีลที่เลยเดือนปิด, Pipeline ที่ต้องมีเพื่อถึงเป้า, snapshot รายสัปดาห์และความแม่นยำย้อนหลัง
7. **โค้ช 1:1**: ตัวเลขของเซลส์แต่ละคนเทียบค่าเฉลี่ยทีม, ข้อตกลงค้างจากครั้งก่อน, ดีลที่ควรคุย,
   AI สรุปประเด็นโค้ช, บันทึกการคุยและ action items
8. **ตั้งค่า**: เป้า GP รายเดือนรายคน, เป้าลูกค้าใหม่, เป้ากิจกรรม, รายชื่อบริษัทในเครือ/สินค้า, โอนงาน

## ข้อมูล (collections)

- `deals`: ลูกค้า, สินค้า, บริษัทภายใน (BU), Billing, GP, ขั้นตอน, % โอกาส, ความร้อน, ช่องทาง,
  เดือนเข้า, เดือนคาดว่าจะปิด, เซลส์, ขั้นตอนถัดไป + วันนัด, Action Plan, หมายเหตุ, เหตุผลที่แพ้,
  เดือนรับรู้ GP + จำนวนเดือนที่กระจาย, ประวัติการเปลี่ยนขั้นตอน
- `accounts`: ชื่อบริษัท, อุตสาหกรรม, เซลส์ผู้ดูแล, รายชื่อเป้าหมาย, ลูกค้าเก่า/ใหม่, ผู้ติดต่อ
- `activities`: วันที่, เวลา, ประเภท, เซลส์, ลูกค้า, ดีล, รายละเอียด, ผล
- `config/settings`: ปี, เป้า, รายชื่อทีม (แก้ได้เฉพาะ Editor/เจ้าของ)

## กติกาที่ระบบใช้คำนวณ

- **นับยอด KPI** = GP ของดีล "ปิดได้ (Won)" ลงในเดือนรับรู้ GP (ค่าเริ่มต้น = เดือนที่ปิด)
  ถ้าเป็นสัญญารายเดือน ตั้ง "กระจาย GP กี่เดือน" ได้
- **คาดการณ์** = GP ของดีลเปิด × % โอกาส ลงในเดือนที่คาดว่าจะปิด
- **ลูกค้าใหม่** = บริษัทที่ปิดดีลแรกได้ในปีนี้ และไม่ได้ติดป้าย "ลูกค้าเก่า"
- **ธงเตือน**: เลยเดือนที่คาดว่าจะปิด, เลยวันนัด, ไม่มีขั้นตอนถัดไป, โอกาส < 70% แต่ไม่มี Action Plan,
  ไม่มี GP, ไม่มีการอัปเดต 14 วัน

- **หมวด Forecast**: ถ้าเซลส์ยังไม่เลือก ระบบเดาจาก % โอกาส (≥80 Commit, 50–79 Best Case) และแสดงเครื่องหมาย ?
- **Pipeline ที่ต้องมี** = ส่วนที่ขาดจากเป้า ÷ win rate ตามมูลค่า (GP ชนะ ÷ GP ที่ปิดแล้วทั้งชนะและแพ้)
  จำนวนดีลที่ต้องสร้าง = ส่วนที่ pipeline ยังไม่พอ ÷ GP เฉลี่ยต่อดีลที่ชนะ (ถ้าชนะน้อยกว่า 3 ดีลใช้ค่าทีม)
- **Conversion**: % ของดีลที่เข้ามาในปีที่ไปถึงขั้นนั้นหรือไกลกว่า ระบบเริ่มเก็บขั้นที่แพ้ (`lostStage`)
  และเวลาเข้าขั้น (`stageAt`) ตั้งแต่เวอร์ชันนี้ ดีลจากชีตเดิมที่แพ้ไปแล้วไม่มีข้อมูลนี้
- **Snapshot** (`snapshots`, 1 เอกสารต่อสัปดาห์): บันทึกเองครั้งแรกที่มีคนเปิดหน้า Forecast ในสัปดาห์นั้น
  ความแม่นยำ = ยอดจริง ÷ Call ของ snapshot สุดท้ายในเดือน
- **บันทึก 1:1** (`coaching`): วันที่, เซลส์, สิ่งที่คุย, ข้อตกลงพร้อมกำหนดเสร็จ
